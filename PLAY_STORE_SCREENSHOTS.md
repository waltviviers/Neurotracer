## Technical Specifications

### Image Format
- **Format**: PNG (recommended) or JPEG
- **Resolution**: 1080 x 1920 px (9:16 ratio)
- **File size**: Optimize to <500 KB per image

### Text Overlay Guidelines
- **Font**: Use a pixel-style font or bold sans-serif
- **Size**: Large enough to read (40-60pt for body text)
- **Color**: White or cyan (#00FFFF)
- **Background**: Semi-transparent black overlay if needed for readability
- **Positioning**: Centered or top/bottom with 60px margin
- **Shadows**: Add subtle drop shadow for text-on-image legibility

### Color Palette
- **Background**: #0A0C0D (dark)
- **Primary**: #00FFFF (cyan)
- **Secondary**: #FFD700 (amber/gold)
- **Accent**: #FF8C00 (orange, for bonus tiles)

## Tips for Screenshot Creation

### Using Flare or Other Tools
- **Record gameplay footage** and extract frames at key moments
- **Add overlays** with text using design software (Figma, Photoshop, Canva)
- **Optimize colors** to match the cyberpunk aesthetic

### Capturing from Device
1. Run the app on an Android device with 1080x1920 resolution
2. Use `adb shell screencap` or built-in screenshot tools
3. Position the UI at key moments (e.g., mid-game, win screen, tutorial)
4. Edit overlays with text in post-production

### Design Tools
- **Figma**: Create mockups and overlay text
- **Photoshop**: Edit and enhance screenshots
- **Canva**: Drag-and-drop screenshot design templates
- **GIMP**: Free alternative for overlays
